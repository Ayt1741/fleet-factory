# fleet-factory — бесплатный вычислительный завод совета

**Что это.** Публичный репозиторий-завод: стандартные GitHub-hosted раннеры на публичных репозиториях
дают **4 ядра / 16 ГБ RAM / 14 ГБ SSD на job, минуты безлимитно, до 20 job одновременно**
(источник: docs.github.com, runners reference + Actions limits, проверено 21.10.2026).
Итого 80 ядер и 320 ГБ RAM в пике — бесплатно, без карты и без телефона.

**Зачем.** У совета 10 руководителей и 30 исполнителей, а «железо» было одно — Codespace 2 ядра / 8 ГБ.
Завод забирает на себя всё, что не требует живого браузера: сборки, тесты, расчёты, массовые PDF,
пакетные проверки, разбор покрытия, подготовку материалов.

**Файлы.**
- `bench.py` — бенчмарк: сколько работы даёт одна машина за фиксированные 20 секунд (stdlib).
- `.github/workflows/burst.yml` — 20 одновременных job: паспорт машины + бенчмарк + артефакт.
- `.github/workflows/heartbeat.yml` — пульс каждые 15 минут: заменяет круглосуточный сервер-«штаб».

**Как читать результат замера.** `walls = длительность всего запуска`, `sum(job durations) = суммарные ядер-секунды`.
Отношение `sum / wall` — сколько машин фактически работало одновременно.

**Чего здесь нельзя.** Секретов, платных раннеров, майнинга, перепродажи вычислений, чужих данных.
Только бесплатные стандартные раннеры и только наши задачи.
